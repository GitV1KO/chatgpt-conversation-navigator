# 测试结果与人工验收

> 历史记录：以下是 1.0.0 的模拟测试，未能覆盖用户真实网页的新 DOM，不能作为 1.0.1 的兼容性证据。当前修复依据用户 Brave 中的实际登录会话完成；本次未运行模拟测试，见 [1.0.1 真实测试记录](LIVE_TESTING.md)。

测试日期：2026 年 10 月 28 日（Asia/Shanghai）。

## 已完成的验证

在 macOS 上用 **Brave 152.0.7977.76 + Playwright 1.64.1** 启动独立临时浏览器资料，通过 `--load-extension` 加载完整的 Manifest V3 扩展。28 项浏览器集成测试通过，无失败；静态清单、脚本语法、图标资源、权限及隐私约束检查通过。

这是浏览器真正加载扩展后的测试：内容脚本由 Manifest 在隔离世界中注入，未用页面脚本替代扩展注入。ChatGPT 域名的文档请求被测试工具直接替换为本地构造的页面，避免访问真实账号或发送真实消息。

完整逐项结果与耗时见 [JSON 报告](../tests/results/browser-results.json) 和 [可读报告](../tests/results/browser-results.md)。以下是覆盖范围：

## 真实 ChatGPT 探测的结果

使用独立、未登录的临时浏览器资料只读访问真实 `https://chatgpt.com/`，返回 **HTTP 403**，页面标题为「请稍候…」，停留在访问验证页面，没有出现聊天输入框。扩展入口注入成功，但这只能证明域名匹配与验证页上的降级显示。

**没有验证真实登录会话中的消息 DOM、实际分支、历史懒加载或真实消息跳转。没有登录、读取日常浏览器资料或发送真实聊天消息。** 未尝试绕过访问验证。

证据：[真实站点探测 JSON](../tests/results/real-site-probe.json)、[探测截图](../tests/results/real-chatgpt-anonymous.png)。复现该只读探测可执行 `node tests/real-site-probe.mjs`，结果取决于网络及站点策略；它不属于默认离线模拟测试。

## 安装后的人工验收

以下项目仍需在你的真实账号与浏览器中完成。建议先选一个已有的非敏感对话，不必为了验收向 ChatGPT 发送内容。

1. **Brave 与 Chrome 安装**：按 README 加载 `extension/`，刷新真实 ChatGPT，确认出现右侧入口。Chrome 本机未安装，因此 Chrome 没有完成原生实测。
2. **历史长对话**：打开几十到上百条提问的历史会话，核对目录只含自己的消息，开头、中间、结尾的不同问题均能准确跳转。相同内容的不同问题应保持独立。
3. **真实新增消息**：在你原本要继续聊天时观察目录自动追加，不需要额外发送测试消息。助手生成过程中面板应稳定。
4. **会话切换**：从历史 A 切换到 B，再去新聊天和自定义 GPT，目录不能混入前一个会话；搜索应重置。测试浏览器前进与后退。
5. **真实历史加载**：在原文未加载时确认显示提示；主动加载可停止，找不到时不得出现成功高亮。若网页未提供更多节点，手动上滚再检查目录。
6. **编辑与分支**：编辑已有问题、切换回答分支，核对旧分支的待定位条目不会跳到其他消息。此版本可能保留旧分支的离屏记录。
7. **缩放与主题**：浏览器原生缩放到 80%、125%、150%、200%，更换网页与系统深浅色主题，并收缩窗口；输入框和发送按钮应可操作。
8. **键盘与阅读位置**：Tab 进入搜索和目录，Enter 跳转、Esc 收起；历史加载中按 Esc 应停止并恢复原阅读位置。直接滚轮应停止加载并保留你选择的位置。
9. **长期使用**：多次切换会话并观察浏览器任务管理器；标签页长期打开、挂起后恢复、操作系统屏幕阅读器及真实触摸输入尚未实测。

## 维护规则

真实网页结构变化时，先记录必要的脱敏 DOM 结构并补充 `fixture.mjs` 的回归用例，再更新 `dom.js`。不能用猜测角色、内容相同或滚动完成作为定位成功的依据。测试网页通过不能替代真实账号的人工验收。
