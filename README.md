# ChatGPT Conversation Navigator

轻量的 Chrome / Brave 扩展：把当前 ChatGPT 对话中已加载的用户提问列成目录，支持中文搜索、快速跳转和短暂高亮。纯 JavaScript、Manifest V3、Shadow DOM，无需构建、后端或 API Key。

当前版本 **1.0.1**。已针对实际 Brave 登录会话修复新版消息标记、隐藏的旧会话容器和虚拟历史扫描。本次真实验证记录见 [LIVE_TESTING.md](docs/LIVE_TESTING.md)；1.0.0 的模拟测试报告不能证明新版真实网页兼容。

**安装用的是 `extension/` 文件夹。源码根目录不是扩展目录。**

## 安装

1. 下载本仓库 ZIP 并解压，或使用 Git 克隆。将本项目放在一个长期保留的位置。浏览器会持续从该文件夹加载扩展，请勿随后移动或删除它。
2. Brave 地址栏打开 `brave://extensions`；Chrome 打开 `chrome://extensions`。
3. 打开右上角的「开发者模式」。
4. 点击「加载已解压的扩展程序」（部分版本叫「加载未打包的扩展程序」）。
5. 选择本项目内的 **`extension` 文件夹**，该文件夹中应直接看见 `manifest.json`。
6. 刷新已经打开的 ChatGPT 标签页，或者新打开 [ChatGPT](https://chatgpt.com/)。
7. 页面右侧会出现「提问导航」按钮。无需登录扩展，也无需额外设置。

也可以解压 `dist/chatgpt-conversation-navigator-1.0.1.zip` 后，选择解压后**直接含 manifest.json 的目录**。ZIP 本身不能通过上述按钮加载。

更新源码后，在扩展管理页点击该扩展的刷新按钮，再刷新 ChatGPT 标签页。浏览器开发者模式的提示属于正常行为；此项目没有上架应用商店或自动更新机制。卸载可在扩展管理页点击「移除」。

## 使用

- 点击「提问导航」展开目录，再点一次或按 `Esc` 收起。面板默认收起，不会为了建立目录自动滚动。
- 列表按可观察的对话顺序排列，只收录用户消息；序号是**当前已索引目录的序号**，加载更早历史后可能变化。
- 每条默认显示约 52 个字符；悬停查看完整提取文本。代码与表格保留文本，图片展示说明或占位，不执行 OCR，也不读取附件文件。
- 搜索框实时筛选，支持中文和英文大小写混合；命中词高亮。命中位置靠后时会显示该位置附近的摘要。点击清空按钮恢复目录。
- 点击问题平滑滚动至原文，验证目标可见后才显示选中状态和约 1.4 秒的高亮。系统开启「减少动态效果」时使用即时滚动。在窄窗口中，成功跳转后自动收起面板便于阅读。
- 新提问、已加载的历史和 SPA 会话切换会自动更新。切换会话清空搜索，展开状态保持。URL 检查以约 900 毫秒为间隔，并在 DOM 变更时立即检查。
- 刷新按钮「重新扫描当前页面」用于网页结构或内容刚发生变化时再次识别；它不会请求聊天接口。

## 尚未加载的历史

**「已索引 N 条」表示扩展看见过的用户消息数量，不代表服务器上完整会话的消息总数。** 扩展不调用 ChatGPT 内部接口，没有读取隐藏历史的特权。

已经索引但后来从页面移出的消息会保留在当前会话内存中，并标记「待定位」。点击时会根据同一回合的占位节点或缓存位置，在有限范围内尝试恢复原文；只有身份、完整文本和可见位置均核对成功才显示已定位。无法找回时提示原因，不跳到附近的问题。

需要更多历史时，可以点击「加载更早消息」。这会主动逐段向上滚动当前对话，等待网页渲染经过的虚拟回合，并收集用户提问；不会直接跳到顶部漏过中间内容。单次最多 120 步或约 30 秒，进度会显示新增数量，未扫描完时再次点击会从上次位置继续。页面顶部会短暂等待网页自身的历史加载。某些回合加载较慢时，仍可能需要手动滚动配合。

加载期间点击「停止加载」或按 `Esc` 可停止并恢复原阅读位置；直接滚动、触摸、点击聊天区域或按页面导航键会停止并保留你主动选择的位置。加载正常结束且没有指定目标时，也会尝试恢复原阅读位置，并校验原回合位置。无法精确恢复时会明确提示“尽量恢复”，网页同时重算高度时仍可能存在偏差。

如果网页没有加载历史、网络延迟过长、目标属于旧分支，或 DOM 信息不足，会显示未找到或无法确认的提示。加载几次仍找不到时，请手动滚动页面。扩展从不把「滚到顶部」当作获得全部历史的证据。

## 隐私与权限

- 仅匹配 `https://chatgpt.com/*` 和 `https://chat.openai.com/*` 的顶层页面。
- 不申请 `cookies`、`tabs`、`storage`、`webRequest`、`scripting` 等浏览器 API 权限；只有这些域名上的静态内容脚本访问范围。
- 不读取 Cookie、Token、站点存储或其他标签页，不访问私有 API，不上传消息。
- 无遥测、广告、远程代码、网络请求或第三方运行依赖。
- 聊天文本和搜索词只保存在当前标签页的内存中；切换会话、刷新或关闭标签页会释放索引。不会自动保存聊天内容。
- 内容脚本运行在浏览器的隔离世界；消息以文本节点显示，聊天中的 HTML 不会变成扩展界面中的可执行内容。

浏览器安装提示中出现「读取和更改 ChatGPT 网站上的数据」是内容脚本功能需要的站点访问范围；本实现仅读取消息 DOM，并加入导航浮层、滚动和临时高亮。网站自身的请求与存储不受扩展控制。

## 开发与验证

安装使用不需要 Node.js。开发测试建议 Node.js 20 或更新版本，以及本地 Chrome / Brave 或 Playwright Chromium：

```sh
npm ci
npm run check
npm test
npm run package
```

`npm test` 会使用独立的临时浏览器配置文件，以 Manifest 真正加载扩展，并把 ChatGPT 域名的请求路由到本地测试网页；它不会打开你的日常浏览器配置或修改真实聊天。测试结束关闭实例并删除临时配置，JSON 与截图保留在 `tests/results/`。

可通过环境变量指定测试浏览器、Playwright 模块或显示测试窗口：

```sh
CGN_BROWSER_EXECUTABLE="/path/to/chrome-or-brave" npm test
CGN_PLAYWRIGHT_MODULE="/absolute/path/to/playwright" npm test
CGN_HEADED=1 npm test
```

没有本地浏览器时先执行 `npx playwright install chromium`。部分 Chrome 品牌版本限制命令行侧载，自动测试优先使用 Brave 或 Playwright Chromium；这不影响开发者模式手动加载。打包脚本需要 Python 3，但安装扩展无需 Python。`tests/real-site-probe.mjs`是独立的真实站点只读探测，不属于默认的离线模拟测试。

当前版本的真实验证见 [LIVE_TESTING.md](docs/LIVE_TESTING.md)。[TESTING.md](docs/TESTING.md) 保留了 1.0.0 的历史测试记录；本次修复没有运行模拟测试。

## 已知限制与维护方向

1. ChatGPT 的网页 DOM 并不是稳定、公开的扩展接口。当前适配器优先用角色属性、回合属性、消息 ID，尽量避开 CSS 类名；网页移除这些信息后需更新 `dom.js`。无法识别时会提示，不能保证未来所有版本都兼容。
2. 没在 DOM 出现过的消息无法预先建目录；虚拟列表、分支切换及懒加载只能根据页面实际提供的节点处理。不会绕过网页安全机制。
3. 没有稳定消息 ID 的结构只按节点维护身份。节点整体重建时，无法证明它与已离屏的同文消息相同，因此可能保留额外待定位记录；不使用相同文字强行合并。无回合编号且加载窗口完全无重叠时，相对顺序可能无法确认，会提示这一限制。
4. 同一 URL 内切换回答分支时，之前看见但已离屏的用户消息可能继续显示「待定位」；扩展不会跳到身份不符的其他分支。
5. 当前不持久化目录和面板设置，没有跨标签页共享、全文回答搜索或快捷键配置。长对话的极大单条消息和数千条目录仍会增加内存及搜索开销。
6. 1.0.1 已在用户的实际 Brave 登录会话中验证；Chrome、其他账号实验版本和更多布局仍需人工验收。没有为了测试发送任何聊天消息。测试通过的范围以真实测试报告为准。

后续优先改进可验证的真实 DOM 适配案例、极长目录的可视化渲染，以及有明确稳定标记时的虚拟列表定位；所有改进应继续保持零上传、最小权限和失败时如实提示。
